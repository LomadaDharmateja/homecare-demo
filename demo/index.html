Five projects, one idea

"AI only reads and understands. Code checks and calculates. A person approves. Everything is logged."

Suggested order if time is short: 1 Intake (2 min), then 5 Onboarding (3 min). The others if they ask.

1 · Request intake

Problem: requests come by form, email and phone notes. Someone reads, sorts and prioritises each one, and urgent cases can get lost.

Show it

  1. Click Emergency. It goes through the n8n webhook, as a web form would (10–30 s).
  2. The phone buzzes: Telegram alert with only case number, service and city.
  3. Below: what the AI extracted and code checked, plus the draft reply.
  4. Right: „Offene Anfragen“ is sorted by urgency. Open „Freigabe“ and approve the draft. Nothing is sent automatically.
  5. Then click Missing info: it detects what's missing (here: the city) and asks for it in the draft.

Send a request


First open Workflow A ↗, click „Execute workflow“ (it then waits for a request), come back here and send. The run then lights up block by block in n8n. One request per click on „Execute workflow“.

Say

"The AI reads the request and fills in a form. Code checks every fact against the original text, sets the priority and writes the draft. A person approves. Emergencies go straight to the phone."

„Jede Anfrage wird in Sekunden sortiert und geprüft. Notfälle landen sofort auf dem Handy. Das Büro gibt nur noch Entwürfe frei.“

Accuracy: 54% in the first version → 18/20 on unseen test cases, 6/6 urgent cases caught.

2 · n8n workflows

Problem: not everything should be custom code. Colleagues should be able to see and change a process themselves.

Show it

  1. Workflow A: webhook → AI service → IF urgent → Telegram, plus a CSV log line.
  2. Click „Executions“ (top of the canvas) and open the run from tab 1: every block shows its data.
  3. Workflow B: every morning, overdue callbacks → summary.
  4. F2 Onboarding: the same idea built only with n8n blocks (data tables, AI nodes, approval form).
  5. If they want the big picture: Diagrams shows all workflows as clickable blocks.

The buttons with ↗ open the n8n editor in its own browser tab (n8n doesn't allow being shown inside another page). Switch back to this tab afterwards. Log in to n8n once before the call.

Say

"n8n is the wiring: trigger in, ask the service, hand out the result. Anyone on the team can open it and see what happens step by step, without reading code."

„n8n verbindet die Systeme. Jeder im Team kann den Ablauf sehen und verstehen, ohne Code zu lesen.“

3 · Questions to the partner data

Problem: head office has numbers for 55 locations. For every question someone builds an Excel sheet by hand.

Show it

  1. Right: choose a question under „Beispielfragen“, e.g. the first one (friends vs. couples vs. solo founders), then „Fragen“.
  2. Show the answer, the chart and „So wurde gerechnet“: the form the AI filled in. Python did the maths.
  3. Ask the English one ("Which locations are furthest below their business plan?").
  4. Tab „Wochenbericht & Hinweise“ → „Bericht dieser Woche erstellen“: early warnings. n8n sends this every Monday.

Say

"The AI only understands the question and fills in a query form. Python calculates every number, so the answer can't invent a figure."

„Die KI versteht die Frage, aber Python rechnet. Deshalb ist jede Zahl richtig und nachprüfbar.“

10/10 German test questions, 13/15 English on the first try.

4 · Handbook assistant

Problem: partners call head office with the same questions again and again, although the answer is in a 100-page handbook.

Show it (choose under „Beispielfragen“, then „Fragen“)

  1. „Bis wann muss ich mit der Pflegekasse abrechnen?“ → answer only from the handbook, with section and department.
  2. „Meine Kundin ist gestürzt und atmet schwer!“ → "call 112" first, fixed text, no AI.
  3. „Welche Software empfiehlt die Zentrale für die Buchhaltung?“ → not in the handbook: it says so honestly.
  4. Tab „Wissenslücken“: that question is now collected, so head office knows what to add.
  5. The English question works too; the answer stays English.

Say

"Answers come only from the handbook, with the source. If it's not in there, it says so and collects the question as a knowledge gap."

„Partner fragen das Handbuch statt die Zentrale. Was nicht drinsteht, wird gesammelt.“

14/15 on unseen test questions; all 3 questions the handbook can't answer were correctly refused.

5 · Onboarding cockpit

Problem: a new partner has 90 days to reach 10 customers. Insurance, permit, training are tracked by email and spreadsheet, so problems show up late.

Show it (n8n version)

  1. Traffic lights: every finding says which rule fired and why. Code only, no AI.
  2. Scroll to „Neues Partner-Update senden“: choose Essen, click the first example ("Wir haben schon 3 Kunden! …"), then „Vorschlag erstellen“.
  3. The proposal shows: office done, insurance blocked, 3 customers, and a warning: customers without insurance. Nothing changed yet.
  4. „Prüfen und freigeben“ opens the n8n form: enter your name, „Alle Änderungen übernehmen“.
  5. Click Reload above the cockpit: Essen is now red, and the audit log shows who approved, with the evidence sentence.
  6. Optional: F2 in the editor → „Executions“ to show the run, block by block.

Say

"Partners keep writing emails. The system turns them into proposals for the checklist, each with the sentence it's based on, and a person approves. I built it twice, in n8n only and with a Python API, and both give the same results."

„Neue Partner schreiben einfach E-Mails. Das System macht daraus Vorschläge, ein Mensch gibt frei, und die Ampel zeigt früh, wer in Gefahr ist.“

47/50 through the live n8n workflow, and never once marked a task as done that wasn't.
